# Licence texts

The [root licence scope](../LICENSE) and [component rights](../docs/COMPONENT_RIGHTS.md)
identify the materials to which each licence applies.

| File | Applies to |
|---|---|
| `MIT.txt` | Author-controlled code and functional configuration requiring the distribution's own MIT notice. |
| `MIT-existing-source.txt` | Exact retained source-component MIT notice with its original CodeProbe contributors attribution. |
| `CC-BY-4.0.txt` | Author-controlled documentation, included figures and research-record rights within the declared scope. |

The full CC BY 4.0 legal text was obtained from its [official plain-text
publication](https://creativecommons.org/licenses/by/4.0/legalcode.txt) and
stored with UTF-8/LF line endings. Creative Commons dedicates the legal text
itself to the public domain. Existing SPDX metadata remains under its stated
CC0-1.0 terms, independently of the software and evidence it describes.
