# Component and distribution boundaries

This `source/` directory is one component of **Source Review Evidence 1.0.0**. The complete distribution contains the selected implementation and retained computational evidence at their declared paths. A smaller GitHub browsing view, if supplied, has its own inventory.

The earlier `CodeProbe_Source_Only_v2.3.0.zip` and the complete historical CodeProbe repository were different objects. Their identities remain component provenance and do not define this distribution's files, version or public record.

The browser configuration retrieves pinned Pyodide bytes at use time. A complete browser runtime is not bundled by this source selection. External runtimes and other prerequisites retain their own notices and availability conditions.

The [root manifest](../DISTRIBUTION_MANIFEST.json) identifies the selected files. [Data](../docs/DATA.md), [provenance](../docs/PROVENANCE.md) and [component rights](../docs/COMPONENT_RIGHTS.md) identify the evidence and rights boundaries. The current metadata does not extend a source licence over every retained record or claim that publication has occurred.
